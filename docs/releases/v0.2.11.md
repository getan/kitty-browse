# v0.2.11 — Shared profile, conversation-local browser views

- Add a profile-owning browser hub with independent browser identities,
  automation sockets, tab collections, selected pages and view lifetimes.
- Add a private cross-process broker for GUI and terminal frontends. Dedicated
  operator capabilities are separate from the automation API and scoped to one
  view; manual input does not implicitly resume paused automation.
- Reconcile only each view's pages and their popups. Closing one view cannot
  close another. Idle owner shutdown retains the persistent profile, while
  heartbeat expiry reclaims views whose frontend crashed.
- Add a remote terminal surface using the existing image encoders and toolbar,
  with native pointer, keyboard, navigation, tab and viewport operations.

Validation: browser-free unit/race suite, build, vet, Linux arm64 and Windows
amd64 cross-builds. Real Chromium end-to-end validation is deferred; it is not
claimed as passing for this release. Existing standalone browser behavior and
the native Chromium sandbox requirements remain unchanged.
